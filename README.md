| Production Unit | Lesson | Status |
|---|---|---|

## Repository Structure

Each lesson is maintained as a complete production unit under `production-units/`, including:

- lesson document and PDF;
- executable notebook;
- student exercises;
- instructor solutions;
- presentation and narration;
- executive brief;
- video and thumbnail materials;
- website and social-media integration materials;
- release evidence, manifests, and checksums.
